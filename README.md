# ManagedOps Control Center

AI-first Managed Services Mobilization, Transition & Operational Readiness platform.

## CMA MVP

The CMA instance starts from the awarded technical proposal and builds a traceable project baseline.

Digital thread:

`Proposal/Contract Requirement -> Position -> Candidate -> Employee -> KT -> Service -> Go-Live Readiness`

## MVP workflow

1. Proposal / Contract ingestion
2. AI extraction with source traceability
3. Human review and approval
4. Project baseline
5. Scope & deliverables
6. Resource plan and recruitment
7. Transition & knowledge transfer
8. Operating model and RAID
9. Service readiness
10. Executive dashboard

## AI principle

Manual entry is the exception. The normal UX is:

`Upload / Connect -> AI Extract -> Review Changes -> Approve -> Dashboard`

AI recommendations never silently become contractual facts. Missing information is marked `To Be Confirmed`, and conflicts are marked `Requires Review`.

## Security

No personal API keys. Production deployments use customer-owned AI credentials through environment variables / secret stores.
